I'm a software engineer with over 20 years of experience. I spent more than 13 years at Oracle, mainly working on OpenJDK, the JDK and JavaFX.

My background is mostly in Java and JVM technologies, although I've also worked quite a lot with C/C++, cross-platform development, debugging and solving compatibility issues.

I decided to start this blog to share some things I find interesting or worth exploring. Most likely, there will be quite a bit about Java and OpenJDK but I don't want to limit it to any particular language or technology.

I enjoy looking into how things actually work, trying different approaches and sometimes discovering something unexpected along the way.

I'll also try to include working code examples whenever possible. You can find them in my [engineering-examples repository](https://github.com/dmarkov20/engineering-examples).

Hopefully, some of these notes will be useful to others too.
